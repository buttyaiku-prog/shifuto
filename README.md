# shifuto — シフト表作成Webアプリ

医療機関1施設（職員21〜50名）向けのシフト表作成Webアプリです。
勤務の自動作成、手動での調整、承認、確定、公開までを一つの流れで扱います。

## 現在の状態

要件定義書 Ver.1.0（2026-10-27）をもとに作った**画面の試作版**があります。

- `prototype/index.html`：「配置を整える」画面の試作版です。ブラウザーで開くだけで動き、サンプルデータを使います。

### 試作版でできること

- 11月分のシフトの自動作成。必要人数、希望休、夜勤回数、契約時間、職員同士の相性を考慮します
- セルを押して勤務を手動で変更。変更した所は自動で固定されます
- 固定した所を残したままの再作成
- 配置不足の一覧表示と、配置候補（注意点つき）の提示
- 確定前チェック。重大違反があると確定できません。理由が必要な警告は、理由を入力すれば確定できます
- 確定、公開、通知方法（メール・LINE・アプリ内）の選択
- CSV（月間一覧型・勤務明細型）の内容の表示とコピー
- 月間表示と週表示の切り替え

### 試作版の制約

- ログイン、データベース、「希望・申請」「職員」「設定」画面はまだありません
- 保存先はブラウザーの localStorage だけです
- 通知は実際には送りません
- 要件定義書で「未決定」の項目は仮の値を使っています。重大違反の分類、勤務間隔の基準11時間、連続勤務の基準5日、CSVの列構成がこれにあたります
