# shifuto — シフト表作成Webアプリ

医療機関1施設（職員21〜50名）向けのシフト表作成Webアプリです。
勤務の自動作成、手動での調整、承認、確定、公開までを一つの流れで扱います。

## 現在の状態

要件定義書 Ver.1.0（2026-10-27）をもとに作った**試作版**があります。

- `prototype/index.html`：ブラウザーで開くだけで動きます。データはサンプルです。
- 画面上部の「表示する立場」で、システム管理者・シフト作成者・一般職員を切り替えて、それぞれの見え方を確認できます。

### 画面

| 画面 | できること |
|---|---|
| シフト（`#shift`） | 自動作成、セルを押して手動変更（自動で固定）、固定を保持した再作成、配置不足と配置候補の表示、確定前チェック（重大違反は確定できず、それ以外は理由を入力すれば確定できる）、確定・公開・通知方法の選択、CSV（月間一覧型・勤務明細型）、月間表示と週表示 |
| シフト（一般職員） | 公開版の閲覧、自分の勤務一覧と月間時間・夜勤回数 |
| 希望・申請（`#requests`） | 希望休・勤務希望・勤務可能時間の登録（締切、個人別の希望休上限）、希望休の承認・却下（却下は理由が必須）、取下げ、公開後の変更申請と承認（反映すると重大違反が増える場合は承認できない） |
| 職員（`#staff`） | 職員の追加・編集・利用停止（雇用区分、月間固定／週契約時間、夜勤の最低・希望・上限、希望休上限、メール）、相性条件（禁止・回避）の登録 |
| 設定（`#config`） | 勤務パターンの追加・編集・削除、必要人数（平日／土日祝）、日付例外、施設カレンダー（祝日・休診日・特別営業日）、希望休締切、警告基準、通知の既定、権限の一覧、操作履歴、サンプルに戻す |

### 試作版の制約

- ログイン（メール認証とパスワード）とサーバー側のデータ保存はまだありません。データはブラウザーの localStorage に自動保存され、ほかの人とは共有されません
- 通知は実際には送りません。CSVはダウンロードではなくコピーです
- 対象月は2026年11月だけです
- 要件定義書で「未決定」の項目は仮の値で動かしています。主なものは次のとおりです
  - 重大違反の分類：承認済み希望休への勤務、勤務時間の重複、相性「禁止」の同時配置
  - 勤務間隔の基準11時間、連続勤務の基準5日（設定画面で変更可）
  - 権限の委任：シフト作成者は確定前チェックまでで、承認・確定・公開はシステム管理者が行う
  - 勤務希望・勤務可能時間は承認なしで登録される
  - CSVの列構成
